# Krona Hills — лендинг житлового кварталу

Концепт-проєкт для портфоліо: односторінковий сайт вигаданого житлового комплексу в сосновому лісі за 22 хвилини від центру Києва. Компанія, ціни і дані вигадані.

Дизайн, тексти і верстка — з нуля, без шаблонів, фото та сторонніх бібліотек. Уся графіка (нічна сцена, карти, планування, будинок, що будується) намальована кодом у SVG.

## Що всередині

1. **Перший екран** — нічна сцена з пагорбами й соснами, вікна поступово вмикаються, паралакс за мишею і при скролі.
2. **Ліс** — інтерактивна карта ділянки: 1 284 сосни і 4 будинки в прогалинах, підказки при наведенні.
3. **Локація** — перемикач «На авто / Без авто», час у дорозі і маршрут на схемі змінюються.
4. **Квартал** — що є на території; жива ілюстрація двору без машин; на телефоні — свайп-стрічка карток.
5. **Квартири** — фільтр, 8 планувань із площами кімнат, вікно квартири (на телефоні — шторка знизу).
6. **Умови покупки** — калькулятор розстрочки та іпотеки; ціна з вікна квартири підставляється автоматично.
7. **Хід будівництва** — будинок, що росте поверх за поверхом, кран, таймлайн, документи.
8. **Питання й відповіді** — плавний акордеон.
9. **Запис на огляд** — форма з маскою телефону, вибором дня і часу, перевіркою полів.

## Технічно

- Чистий HTML, CSS і JavaScript — без фреймворків і збірки.
- Mobile-first, перевірено на ширинах від 320 до 1920 px.
- Доступність: контраст тексту за WCAG AA, навігація з клавіатури, підтримка «зменшити рух» у системі.
- Шрифти: Unbounded, Onest, IBM Plex Mono (Google Fonts).

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер:

```bash
python3 -m http.server 8000
```

і перейдіть на http://localhost:8000.

## Публікація на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save. Через хвилину сайт буде доступний за адресою `https://<ваш-логін>.github.io/krona-hills/`.

## Примітка

Форма запису — демо: дані нікуди не надсилаються. Для справжнього сайту підключіть відправку у функції обробки форми в `js/main.js` (місце позначене коментарем).
